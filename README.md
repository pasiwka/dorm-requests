# CampusNet — Система управления заявками общежития

## О проекте

CampusNet — это учебное веб-приложение для управления заявками студентов общежития. Система объединяет:

- статический фронтенд на HTML, SCSS и чистом JavaScript
- REST API на Node.js и Express
- аутентификацию через JWT
- SQLite в качестве базы данных

Проект демонстрирует работу с адаптивной вёрсткой, БЭМ, клиентским JavaScript и серверной логикой.

---

## Функции

### Для студента

- вход по телефону и паролю
- просмотр личного профиля и данных проживания
- создание новой заявки на обслуживание
- просмотр списка собственных заявок
- отслеживание статуса заявки

### Для администратора

- просмотр всех заявок
- изменение статуса заявки
- добавление комментариев администратора
- доступ к данным всех пользователей

---

## Технологический стек

- Frontend: HTML5, SCSS, JavaScript (ES6+)
- Backend: Node.js, Express.js
- База данных: SQLite3
- Аутентификация: bcrypt, JWT
- Менеджер пакетов: npm

---

## Структура проекта

- `backend/` — серверная часть на Node.js
- `backend/server.js` — основной API-сервер
- `backend/database.js` — подключение к SQLite
- `backend/auth.js` — JWT-мидлвейр
- `frontend/pages/` — статические страницы интерфейса
- `frontend/js/` — клиентская логика
- `frontend/styles/` — SCSS и итоговый CSS

---

## Аутентификация и безопасность

- Пользователь входит в систему через `POST /api/login`
- При успешном входе сервер возвращает JWT-токен
- Токен требуется для защищённых маршрутов
- Пароли хранятся в базе с использованием bcrypt
- В production рекомендуется задавать переменную окружения `JWT_SECRET`

---

## Основные API маршруты

| Метод | URL | Доступ | Описание |
|---|---|---|---|
| POST | `/api/login` | public | Вход по телефону и паролю, возвращает JWT |
| GET | `/api/users/:userId` | auth | Получение профиля пользователя |
| PUT | `/api/users/:userId` | auth | Обновление имени и фамилии пользователя |
| GET | `/api/rooms/find` | public | Поиск комнаты по корпусу и номеру |
| PUT | `/api/residencies/:userId` | auth | Обновление текущего проживания пользователя |
| GET | `/api/requests` | admin | Получение всех заявок |
| GET | `/api/requests/user/:userId` | auth | Получение заявок пользователя |
| POST | `/api/requests` | auth | Создание новой заявки |
| PUT | `/api/requests/:id/status` | admin | Обновление статуса заявки |

## Запуск проекта

```bash
cd backend
npm install
npm start
```

После запуска сервер будет доступен по адресу `http://localhost:3000`.

Откройте в браузере `frontend/pages/login.html` для входа в приложение.

---

## Установка и рекомендации

- Убедитесь, что на машине установлен Node.js 18+.
- Если планируется использование в рабочем окружении, задайте `JWT_SECRET`.
- Для отладки используйте консоль браузера и Network в DevTools.

---

## Примечания

- Маршруты защищены JWT и проверяют роль пользователя (`student` или `admin`).
- Для существующих пользователей пароли автоматически мигрируются в bcrypt при первом успешном входе.
- Проект предназначен для учебных целей и требует доработки перед реальным деплоем.
